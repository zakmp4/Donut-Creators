The server

What is DonutSMP?

DonutSMP is one of the biggest Minecraft survival servers around. You start with nothing and grind for loot, money and gear, then fight other players to climb to the top.

There are almost no safe zones: griefing, stealing and PvP are all allowed, which is exactly why it makes such good content. Every base raid, crate opening and comeback is a story waiting to be recorded.

You can join from Java or Bedrock using the same address, on any modern version from 1.20 up.
